# 浮汐待办计划

排序原则：**先不出事，再补功能，最后做体验**。P0 全部完成前不放宽白名单。
量：S ≈ 半天内，M ≈ 1~2 天，L ≈ 更久或需要逆向研究。

## P0 · 稳定与安全（放宽白名单的前提）

已于 2026-11-24 全部完成并在线上验证：三个会话的 OCR 核对、停机期间消息补回复、
只重建内核后 watchdog 约 1 分钟内自动重建 bridge。Kuma Push 监控已建好并接入 watchdog。

- [x] **P0-2 主动告警（S）**：熔断、微信掉线/待登录、密钥解不出、桥接反复重启时推送 Bark；

- [x] **P0-5 防封与拟人节奏（S）**：每会话/全局每分钟发送上限、按长度模拟打字延迟、随机抖动、可选夜间静默。

## P1 · 功能补全（接通内核已有能力）

- [x] **回复提速（S）**：搜索并进入会话从约 5 秒降到 1.3~1.9 秒（目标 2 秒内）：截图扫描改 numpy、
      按键合并、固定等待改为轮询（等下拉结果连续稳定再点）、标题 OCR 只跑识别模型（0.6 秒 → 0.02 秒）、
      同一会话连发跳过搜索。日志与 `/healthz` 记录耗时。
- [x] **全链路耗时统计（S）**：每次自动回复记录 发现/合并/内核/打字/排队/进会话/粘贴/核对 各段，
      日志 `回复耗时`、`/healthz` 的 `latency`、遥控 `/状态` 可看。首轮实测：首条 10~17 秒，
      其中模拟打字约占一半，核对只有 0.05~0.3 秒（不是瓶颈）。
      已调整：第一个气泡的打字时间扣掉模型已花的时间（像人边想边打），后续气泡不变。
- [x] **搜索误判修复**：会话内容里提到会话名时，「聊天记录」分区也会出现整行标绿的标题，
      导致「不唯一」而拒发。现在 OCR 分区标题，只点「联系人/群聊/功能/最常使用」里的匹配行。
- [x] **发送容错（S）**：偶发失败不再误熔断。进会话出错（截图失败、结果没稳定、标题读错）与
      粘贴前出错都只放弃这一条并 1.5 秒后重试一次；粘贴前先点输入框、全选再粘贴（替换别人留的草稿）；
      核对忽略空白差异。仍熔断：回车后出错、发出后数据库核对不到。分区标题 OCR 容错（「君群聊」）。
- [x] **引用 / 链接 / 文件消息（S）**：解析 type 49 appmsg：引用（附被引用内容，引用 bot 时
      `reply_to_bot`）、链接（带 URL 交给内核抓摘要）、文件、小程序、聊天记录、视频号、音乐、拍一拍我；
      转账红包不交给模型。
- [x] **图片/语音等占位（S）**：图片、语音、视频、动画表情、位置、名片以「[图片]」「[语音 5秒]」
      「[位置] 西湖 …」等占位交给内核，不再被无视（真正看懂内容见下方「图片理解」「语音」）。
- [x] **撤回不回（S）**：交给内核前、发出第一个气泡前各查一次库，撤回的消息（原行被改写成
      revokemsg 或已不在）不再回复；生成回复期间撤回则整次放弃。
- [x] **真 @（M）**：群里打 `@` + 名字（只取第一个空格/@ 之前，否则成员框会关掉或再弹一个）→ 截图比对找出
      成员弹窗 → 恰好一行且 OCR 名字一致才**点击**（不按回车，弹窗意外关闭也不会误发）→ 再 OCR 输入框确认是
      「@完整名字」→ 粘贴正文发送。名字用群昵称（解析 `chat_room.ext_buffer`），任何一步不符就清空改用文字 @。
      模型回复自带的「@名字」开头会被去掉，不再重复。每次约多 3.5 秒。
- [x] **主动搭话（S）**：桥接每分钟问内核 `/api/care/due`（时间段 / 间隔 / 每日上限 / 只找主人都由内核判断），
      该发就 `/api/care` 生成一句、发出、`/api/care/sent` 记账。桥接再加闸：暂停 / 熔断 / 静默时段不发、
      目标须在白名单、最近 20 分钟有聊天的会话不打扰（生成后再查一次）。主人用 `/设置 主人` 配置；
      遥控 `/搭话` 立即检查一次，`/状态` 显示今天次数和当前不发的原因。
- [x] **表情包（S）**：内核在回复里预留表情包任务，桥接发完文字后 claim → 发送 → ack；文字没发完就 cancel。
      GIF 按「文件」粘贴（经与微信容器共享的 X11 目录），微信原样发成动画表情；按图片粘贴会变静态图。
      `/设置 表情包 开`；图库用遥控 `/存表情 开心|傲娇|炸毛`（下载最近发到文件传输助手的表情原图交给内核）。
      顺带：一个气泡发送失败后不再接着发后面的气泡。
- [x] **图片理解（L）**：消息行 `packed_info_data` 里取文件名 → 找 `msg/attach/<md5(会话)>/*/Img/<名>[_h|_t].dat`
      （原图最多等 8 秒，否则用缩略图）→ V2 解密（AES 密钥 = md5(uin+wxid) 前 16 位，异或字节 = uin 低 8 位；
      uin 用缩略图 JPEG 结尾反推异或字节后在 2^24 内暴力找，几秒，存 `/state/imgkey.json`）→ wxgf（HEVC）用
      OpenCV 解第一帧 → JPEG 交内核 `/api/vision`，描述附在「[图片]」后面。只看最后发言人的最多 3 张；
      失败保留占位。`/设置 看图 全部|只看私聊|关闭`。
- [x] **语音（M）**：消息行 server_id → `message/media_*.db` 的 VoiceInfo 取 SILK（腾讯版，开头多 0x02）→
      silk-python 解成 16 kHz WAV → 内核扩展 `POST /api/fuxi/asr`（`kernel/fuxi/asr.js`，用内核 voice 配置，
      默认跟随聊天服务商：DeepSeek `/v1/tools/asr` 或千问 `qwen3-asr-flash`）→ 文字附在「[语音 N秒]」后面。
      `/设置 语音转文字 全部|只听私聊|关闭`；失败保留占位。

- [x] **设置集中管理（S）**：行为开关从 `.env` 搬到桥接状态卷的 `settings.json`（`settings.py` 登记每项的
      类型/默认值/说明），改了立即生效；遥控 `/设置`、API `GET/POST /settings`（管理台用）。内核管的项
      （表情包）只转发。旧环境变量只在第一次生成文件时搬一次。

- [ ] **链接读取改进（S）**：现在只抽 og 标题/简介 + 前几个 `<p>`，截 600 字，GitHub 页抽到的全是导航。
      在 `kernel/fuxi/preload.js` 里替换内核的 `linkReader`（不改上游）：正文提取换 Readability 一类的库、
      上限提到 2000~3000 字；GitHub 取 README 原文、B 站取简介。第三方阅读服务做成设置项默认关。
      详见 [feedback-loop.md](feedback-loop.md) 第一节。

## P2 · 与浮屿打通

群反馈闭环的完整设计见 [feedback-loop.md](feedback-loop.md)。已定：只收集浮屿用户群一个群；
修复默认走云端 GitHub Action，需要本机构建的走 Mac 本地；开 issue、合并、发版都要主人点头。

- [ ] **F1 反馈收集 + 每日摘要（M）**：桥接把浮屿用户群的消息（含图片描述、语音转文字）攒批交给 DeepSeek，
      分成 bug / 建议 / 提问 / 无关并合并同一问题，存 `/state` 反馈库；每天私聊主人一份带编号的摘要。
      先只出摘要，跑一两周看分类准确度。
- [ ] **F2 浮屿仓库只读同步（M）**：只读 token 定时同步 Releases / Issues / PR / commits（机房走代理）；
      新反馈查重、标「已知 / 已修于 vX」；群里问「修了没」bot 按缓存回答；合并或发版后回群通知原反馈人
      （轮询，不对公网开 webhook）。
- [ ] **F3 批准后开 issue + agent 修复（L）**：遥控 `/修 N` `/忽略 N`；批准后脱敏开 issue（`from-wechat`，
      写 token 与只读 token 分开）；浮屿仓库装 Claude Code Action 出 draft PR；可选 Mac 守护进程领
      `fix-local` 的 issue，起 T3 Code / `claude -p` 在独立 worktree 修。群友原话只作问题描述，agent 无密钥、不自动合并。
- [ ] **待补信息**：浮屿仓库地址与公开/私有、用户群 chat_id、摘要发送时间与去处。

- [x] **发版自动发群（S）**：`POST /announce {key, text, image_base64}` 先把内容发到文件传输助手预览，
      主人回 `/发布 编号` 才发群（`/取消`、`/待发`；24 小时过期）；key 幂等，状态存状态卷，重跑不重复预览/发群。
      目标群用 `/设置 发版群`。浮屿侧：`pnpm release` / `release:share --push` 在本机设了
      `FUYU_FUXI=<ssh 主机>:<部署目录>` 时经 ssh 调用（token 走 curl 配置文件，不进命令行）。
- [ ] **用户群产品助手（M）**：浮屿用户群专用人设，知识来源为浮屿文档与 CHANGELOG；被 @ 提问时
      按文档回答，答不上转人工。依赖 P0-1、P0-5。CHANGELOG / 版本信息复用 F2 的仓库同步缓存。
- [ ] **API 增强（M）**：异步任务 + 状态查询、定时发送、消息模板；若浮屿在 CI 发版，设计安全访问方式。
