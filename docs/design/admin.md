# 管理台界面约定

更新：2026-11-24（初版，用户看过 [admin-preview.html](admin-preview.html) 后同意按这个方向做）

架构、接口和开发流程见 [../admin.md](../admin.md)。这里只管「长什么样、怎么交互」。
每条后面标出处：（用户确认）是用户定的；（Agent 推断）是做的时候自己定的，用户没反对前照此执行，改了要回来更新。

## 总方向

- 和浮屿是一家人：沿用浮屿设置窗口的视觉，不另建主题。深色表面、圆角卡片、系统字体、lucide 图标、浅蓝强调色。（用户确认）
- 技术栈 React + Vite + TypeScript + lucide-react，和浮屿相同；不引入 MUI、shadcn、Tailwind 等组件库或样式框架，组件自己写。（用户确认）
- 用的人只有主人一个；优先「一眼看清现在怎么样」和「改一个设置很快」，不做多用户、权限分级。（Agent 推断）
- 手机上要能用：出门在外打开看状态、暂停回复、点发布公告。（Agent 推断）

## 视觉变量

- 颜色、圆角、间距、动效时长从浮屿 `src/styles/tokens.css` 抄过来，放在 `bridge/admin/src/styles/tokens.css`，变量名保持一致（`--color-text`、`--color-white-a06`、`--radius-xl`、`--motion-base`……），以后对照浮屿改起来方便。只抄用得到的，不抄岛和 Agent 专用的。（用户确认抄浮屿；取舍为 Agent 推断）
- 浮屿的浅色是 `.island-light` 类，这里改成 `:root[data-theme="light"]`，值不变。（Agent 推断）
- 深浅色：默认跟随系统，侧栏底部一个按钮手动切换，选择存 `localStorage`（读写都包 try/catch，读不到就跟随系统）。（Agent 推断）
- 字体：系统字体栈，Mac 上 `-apple-system` / 苹方在前，Windows 上 Segoe UI Variable / 微软雅黑；数字用 `font-variant-numeric: tabular-nums`；时间、版本号、耗时这类机器值用等宽。（Agent 推断）
- 状态色只用四种，带同色 3px 光晕的小圆点：正常 `#34c759`、注意 `#ffd60a`、出错 `#ff453a`、未知/停用 `#8e8e93`（取自浮屿的状态灯色）。不单靠颜色传达状态，圆点旁边一定有文字。（Agent 推断）
- 强调色 `--color-accent`（深色 `#74d6ff`、浅色 `#0a7fd1`）只用在：选中项、开关打开、主按钮、链接、bot 的回复气泡。（Agent 推断）

## 布局

- 左侧栏 196px + 右侧内容区；内容最宽 860px 居中，和浮屿设置窗口的右侧一样宽。（用户确认；侧栏宽度比浮屿的 172 宽一点，放得下「发版公告」加角标，Agent 推断）
- 侧栏从上到下：品牌（水波图标 + 「浮汐」）、搜索框、分组导航、底部一行（当前版本号 + 深浅色切换）。（用户确认，见预览）
- 宽度 ≤ 760px：侧栏收成抽屉，页标题左边出菜单按钮，点遮罩关闭；卡片里的行允许换行；统计磁贴两列。最窄按 360px 设计，不出现横向滚动。（Agent 推断）
- 页面结构：页标题（20px，粗 650）→ 可选的顶部标签（选中项加粗 + 2px 强调色下划线，左右方向键切换）→ 若干「组」。（照浮屿）
- 组 = 13px 粗体组标题（右边可放灰色补充信息或一个操作）+ 卡片（`--color-white-a04` 底、`a06` 边、12px 圆角）+ 可选脚注（12px 灰字）。卡片里的行之间是左右各缩进 16px 的细分隔线。（照浮屿 SettingsGroup）
- 行 = 可选的 30px 图标块 + 标题/说明两行文字 + 右侧控件；最小高 52px，内边距 11px 16px。（照浮屿 SettingsRow）

## 组件

只做下面这些，新页面先用它们拼，不够再加（加了写进这里）：

- **开关**：40×24，打开是强调色。（照浮屿 SettingsSwitch）
- **分段选择**：2–4 个选项的单选，用于 choice 类设置和列表筛选。（照浮屿 SettingsChoice）
- **输入框**：30px 高；数字右对齐、窄一些。失焦或回车保存，不需要单独的「保存」按钮；保存中输入框右侧转圈，失败原地红字 + 恢复原值。（Agent 推断）
- **标签输入**：list 类设置（主人、bot 名字、产品助手群……），每项一个胶囊带 ×，末尾虚线「＋ 添加」。添加会话类的项时弹出会话搜索。（Agent 推断）
- **按钮**：普通、主按钮（强调色实心，一屏最多一个）、危险（红字）。30px 高。（Agent 推断）
- **确认条**：危险操作（移出白名单、发布公告、发送、重启）不弹浏览器对话框，在那一行下面展开一条浅红底的确认条：一句话说清后果 + 取消 + 确认。（照浮屿 SettingsInlineConfirm）
- **状态胶囊**：圆点 + 一句话，用在概览顶部和服务卡片。（Agent 推断）
- **小标签**：18px 高的灰/强调色/薄荷/黄色小块，标会话类型、@我、附资料、等确认这类属性。（Agent 推断）
- **统计磁贴**：标签 + 大数字 + 小字或迷你柱状图。（Agent 推断）
- **消息条目**：头像（会话名首字 + 按名字取色）、会话名、发送人、标签、时间；收到的内容；bot 回复放在浅蓝气泡里；下面一根耗时分段条和图例。（Agent 推断）
- **空状态**：图标 + 一句话 + 可选的下一步按钮。（Agent 推断）

## 交互

- 改设置立即生效，和文件传输助手里 `/设置` 是同一份；页面上的值以服务端返回为准，别处改了（比如遥控指令）几秒内同步过来。（用户确认「同一份」；同步方式为 Agent 推断）
- 加载：首屏用灰色骨架占位，不用整页转圈；之后的刷新不闪。（Agent 推断）
- 出错：在出错的那张卡片里写原因 + 「重试」，不弹窗、不清空已有内容。连不上服务端时顶部一条黄色细条「连不上浮汐，N 秒后重试」。（照浮屿「失败时原地给出重试」）
- 实时：对话流和概览走服务端推送；页标题右侧一个「实时」薄荷绿呼吸点，断开时变灰并写「已断开，重连中」。（Agent 推断）
- 写操作成功后不弹 toast，控件本身的状态变化就是反馈；只有结果不在当前视野里时（如「已发出」）才在那一行显示 3 秒的小字。（Agent 推断）
- 键盘：Tab 顺序和视觉顺序一致；所有可点的东西有焦点环（`--color-focus-ring`，2px，偏移 2px）；`/` 聚焦侧栏搜索。（Agent 推断）

## 动效

- 照浮屿 [motion.md](https://github.com/TixXin/Fuyu/blob/main/docs/design/motion.md) 的曲线和时长变量：控件状态 120–160ms，换页内容上移 6px 淡入 240ms。（Agent 推断）
- 系统要求减少动画（`prefers-reduced-motion`）时去掉所有位移和呼吸动画，只保留瞬时切换。（照浮屿）

## 文案

- 大白话中文，和遥控指令、`/状态` 的说法一致：「白名单」「静默时段」「转人工」「熔断」不另起新名词。（Agent 推断）
- 说后果，不说实现：「移出后浮汐不再回她的消息」，而不是「从 allowlist 删除」。（Agent 推断）
- 时间：今天的只写 `20:52`，更早的写 `11-23 20:52`；耗时保留一位小数加 `s`。（Agent 推断）

## 预览与截图

- 定方案先做静态 HTML 预览放在本目录（如 [admin-preview.html](admin-preview.html)），用户看过再写代码。（照浮屿的做法）
- 预览、截图、测试里的会话名、人名、消息全部编造，不放真实联系人、私人群名、wxid 和聊天内容；「浮屿用户交流群」这类本来就公开的群名可以用。（Agent 推断，和仓库的密钥扫描一致）
