# 每周换浮屿群二维码

微信群二维码 7 天过期。浮屿仓库 `main` 上的 `docs/assets/community/`（应用「设置 → 关于 → 帮助」读它）和 README 里放着群码，浮汐每周自动换。代码在 `bridge/fuxi_bridge/groupqr.py`，浮屿那边的说明见浮屿仓库 `docs/features/community.md`。

## 流程

1. 每分钟的群后台任务里看一眼：仓库里这个群的 `expiresAt`（码最后有效那天）到了，或者上次换到的码满 7 天，每 30 分钟试一次；有人在网页版微信里操作（2 分钟内）就先不动。
2. 拿着发送锁操作界面：搜索打开群 → 右上角「…」→ 群信息面板里找 OCR 文字完全等于「群二维码」的一行（面板里还有「退出群聊」「清空聊天记录」，只认这一个字样）→ 点开，整屏截图，zxing / OpenCV 解出 `https://weixin.qq.com/g/...`，OCR 读「X 月 Y 日前有效」。
3. 关掉二维码小窗和群信息面板（不在聊天里按 Esc，会把主窗口收进托盘），放锁。
4. 链接和仓库里那张图解出来的一样：旧码还没过期，下次再试。不一样：裁出二维码（白底黑码 480×480，解不出原链接就用链接重新生成），改 `community.json` 的 `expiresAt`（Y 的前一天）和 `updatedAt`，三个文件一起用 GitHub API 提交到新分支 `community/wechat-qr-*`，开 PR，用管理员 token squash 合并。浮屿的 `ci.yml` 对只改这三个文件的 PR 和推送不跑 CI，PR 上没有 `check`，靠管理员身份绕过规则集。
5. 换好私聊主人；失败每天最多私聊一次，30 分钟后再试。

## 配置

- 设置「换码群」：群名，如 `/设置 换码群 浮屿用户交流群`；空 = 不换。浮汐要在群里；群开了「群聊邀请确认」时最好设成管理员。
- `.env` 的 `FUXI_GITHUB_QR_TOKEN`：浮屿仓库**管理员账号**的细粒度 token，只授权浮屿仓库，Contents 和 Pull requests 读写。不是管理员的 token 合并会被规则集拒绝，PR 留在那里，失败私聊里会带 PR 链接。改完重建 bridge。
- 仓库跟「资料仓库」设置（默认 `TixXin/Fuyu`）。

## 遥控

| 指令 | 做什么 |
|---|---|
| `/换码` | 状态：仓库里的码有效到哪天、上次检查、上次 PR、上次出错 |
| `/换码 预演` | 打开群二维码、解码、把会提交的图发给你，不开 PR；第一次部署后先跑这个，用手机扫一下 |
| `/换码 立即` | 不看日期马上检查，链接变了就换 |

## 限制

- 群超过 200 人后微信不能扫码进群，换码也没用了，到时改企业微信群活码或个人码（浮屿 `docs/research/wechat-group-qr-refresh.md`）。
- 微信改版后菜单位置变了会找不到「群二维码」，失败私聊里会说；`/换码 预演` 排查。
