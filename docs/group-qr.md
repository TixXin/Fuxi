# 每晚换浮屿群二维码

微信群二维码 7 天过期。浮屿仓库 `main` 上的 `docs/assets/community/`（应用「设置 → 关于 → 帮助」读它）和 README 里放着群码，浮汐每晚自动换。代码在 `bridge/fuxi_bridge/groupqr.py`，浮屿那边的说明见浮屿仓库 `docs/features/community.md`。

微信每次打开「群二维码」都给一条新链接，有效期是打开那天往后 7 天（显示「X 月 Y 日前有效」）。所以每晚换一次，仓库里的码一直还剩 6 天以上，应用里不会出现「已过期」。

## 流程

1. 每分钟的群后台任务里看一眼：到了「换码时间」（默认 00:00）且今天还没换过，或者仓库里这个群的 `expiresAt`（码最后有效那天）到了，就动手；没成功每 30 分钟再试。有人在网页版微信里操作（2 分钟内）就先不动。
2. 拿着发送锁操作界面（约 6 秒）：搜索打开群 → 右上角「…」→ 群信息面板滚到底，只识别面板那一块，找 OCR 文字完全等于「群二维码」的一行（面板里还有「退出群聊」「清空聊天记录」，只认这一个字样）→ 点开二维码小窗，zxing / OpenCV 解出 `https://weixin.qq.com/g/...`，OCR 读二维码下面的「X 月 Y 日前有效」。
3. 点小窗右上角 × 关掉，再点「…」收起面板，放锁。全程不按 Esc（Esc 落到主窗口会把它收进托盘）。
4. 新码有效期不比仓库里的晚：不换（当天算换过）。否则：
   - 应用用的 `docs/assets/community/wechat-group.png`：裁出的纯二维码，白底黑码 480×480（解不出原链接就用链接重新生成）；应用自己在码下面写有效期。
   - README 用的 `docs/assets/readme/wechat-group.png`：同一个码，上面加「群聊：群名」，下面加「有效期至 YYYY-MM-DD」（字体文泉驿微米黑，镜像里装了 `fonts-wqy-microhei`）。
   - `community.json` 改 `expiresAt`（Y 的前一天）和 `updatedAt`。
   - 三个文件用 GitHub API 提交到新分支 `community/wechat-qr-*`，开 PR，用管理员 token squash 合并。浮屿的 `ci.yml` 对只改这三个文件的 PR 和推送不跑 CI，PR 上没有 `check`，靠管理员身份绕过规则集。
5. 每晚换成功不打扰；码到期才换的、`/换码 立即` 换的会私聊主人。失败每天最多私聊一次。

## 配置

- 设置「换码群」：群名，如 `/设置 换码群 浮屿用户交流群`；空 = 不换。浮汐要在群里；群开了「群聊邀请确认」时最好设成管理员。
- 设置「换码时间」：每天几点换，默认 `00:00`（写 `24:00` 也行）；空 = 只在码到最后有效那天才换。
- `.env` 的 `FUXI_GITHUB_QR_TOKEN`：浮屿仓库**管理员账号**的细粒度 token，只授权浮屿仓库，Contents 和 Pull requests 读写。不是管理员的 token 合并会被规则集拒绝，PR 留在那里，失败私聊里会带 PR 链接。改完重建 bridge。
- 仓库跟「资料仓库」设置（默认 `TixXin/Fuyu`）。

## 遥控

| 指令 | 做什么 |
|---|---|
| `/换码` | 状态：仓库里的码有效到哪天、换码时间、上次检查、上次 PR、上次出错 |
| `/换码 预演` | 打开群二维码、解码，把 README 会用的图发给你，不开 PR（不需要 token）；第一次部署后先跑这个，用手机扫一下 |
| `/换码 立即` | 不看时间马上检查，新码有效期更晚就换 |

## 限制

- 群超过 200 人后微信不能扫码进群，换码也没用了，到时改企业微信群活码或个人码（浮屿 `docs/research/wechat-group-qr-refresh.md`）。
- 微信改版后菜单位置变了会找不到「群二维码」，失败私聊里会说；`/换码 预演` 排查。
- 每晚一个 PR 合进浮屿 `main`，一周 7 个只改图片和 JSON 的提交。
